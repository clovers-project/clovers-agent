# 任务七：用户反馈分类与优先级判断

> 本题为纯文本任务，所有信息均在题干中，无需联网或调用工具。

某在线课程平台收到以下 6 条用户反馈：

| 编号 | 反馈内容 |
|---|---|
| R1 | 课程讲得很细，老师答疑也快，就是 App 每次打开都要重新登录，有点烦。 |
| R2 | 买了三天，发现内容和详情页写的完全不一样，申请退款还被机器人来回踢皮球。 |
| R3 | 这个价格能买到这么多实操案例，超出预期，已经推荐给同事了。 |
| R4 | 直播课声音一直卡，老师讲什么根本听不清，客服说是我网络问题，可我换了两条网线都一样。 |
| R5 | 课程不错，但更新太慢，第五章等了两个月还没上线。 |
| R6 | 本来只是想试听，结果被销售连续打了五个电话，体验很差。 |

**分类维度：**

- **主要类别**（只能选一个）：课程内容 / 技术故障 / 售后服务 / 价格与退款 / 营销与销售 / 其他
- **情感分值**：+2（明确满意/推荐）、+1（总体正面但有保留）、0（中性或正负相当）、-1（明显不满但仍有肯定）、-2（强烈不满/要求退款/流失风险）
- **紧急度**：高 / 中 / 低
- **是否需人工跟进**：是 / 否

**任务：**

1. 为每条反馈填写上述四个维度，并用不超过 30 字说明判断依据。若一条反馈包含多个问题，以“用户最想解决的那个问题”作为主要类别。
2. 从“影响范围、合规/资金风险、可恢复性”三个角度，给出人工处理的优先级排序（只排前三名），并解释为什么不能只按情感分值排序。
3. 指出哪一条反馈最容易被误判为“普通好评”，并说明误判的后果。

| R6 |  |  |  |  |  |

**优先级排序：** 1. ……　2. ……　3. ……
