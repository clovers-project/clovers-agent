# 任务三：逻辑推理

> 本题为纯文本任务，所有信息均在题干中，无需联网或调用工具。

五位同事——A、B、C、D、E——并排坐在一排五个座位上，座位从左到右编号为 1、2、3、4、5。已知：

1. A 坐在正中间的座位上。
2. B 紧挨着坐在 C 的左边（即 B 的座位号比 C 小 1）。
3. D 不坐在两端。
4. E 坐在 A 的左边（不要求相邻）。
5. C 不与 A 相邻。

请回答：

1. 五个人的座位顺序（按 1→5 写出）。
2. 给出逐步推理过程，说明每一步排除了哪些可能性。
3. 验证你的答案满足全部五个条件。

**要求：**

- 必须说明本题有唯一解，并用排除法证明；不要只写最终答案。
- 推理过程用编号步骤或表格呈现。
- 不要引入题干之外的假设（例如“每个人必须认识彼此”）。

**输出格式：**

**最终座位：** 1. ___　2. ___　3. ___　4. ___　5. ___

**推理过程：** ……

**验证：** ……
