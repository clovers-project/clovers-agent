# 任务八：数据解读与经营建议

> 本题为纯文本任务，所有信息均在题干中，无需联网或调用工具。

某连锁品牌有四家门店。以下是 9 月和 10 月的经营数据：

| 门店 | 9 月营收（万元） | 10 月营收（万元） | 9 月订单数 | 10 月订单数 |
|---|---:|---:|---:|---:|
| A | 120 | 132 | 6,000 | 6,600 |
| B | 100 | 90 | 5,000 | 4,000 |
| C | 80 | 96 | 4,000 | 4,800 |
| D | 60 | 66 | 3,000 | 3,600 |

客单价 = 营收 ÷ 订单数。

**任务：**

1. 计算并填写下表（百分比保留一位小数，客单价保留整数或一位小数），并增加“合计”行：

| 门店 | 营收环比 | 订单数环比 | 10 月客单价（元） | 客单价环比 |
|---|---:|---:|---:|---:|
| A |  |  |  |  |
| B |  |  |  |  |
| C |  |  |  |  |
| D |  |  |  |  |
| 合计 |  |  |  |  |

2. 分别按 10 月营收和 10 月客单价对四家门店排序，指出两种排序的差异说明了什么。
3. 判断哪家门店的“增长质量”最高，哪家存在“增收不增质”的风险。必须用至少两个指标说明，不能只看营收。
4. 针对 B、D 两家门店各给一条可执行建议，并写明建议要改善的具体指标。
5. 指出仅凭这张表进行判断时，最需要补充哪两类信息，并说明原因。

**要求：**

- 写出关键计算过程或公式，不要只给结论。
- 所有百分比保留一位小数；若四舍五入后相同，请说明。
- 不推断表中没有的因果关系（例如“因为打折所以客单价下降”只能作为假设，不能写成事实）。
